# Architecture rules
- Keep incomplete team profiles in a separate, unrendered draft registry; public team and executive lists must contain only ready-to-publish profiles.
- Keep contact inquiry formatting in a browser-safe utility used by the existing email handoff; this preserves submission behavior and allows concrete data-flow tests.
- Keep supplied editorial features in browser-safe data modules consumed by the existing article route and listing; optional per-feature credits preserve source attribution without changing other authors.
